- **开箱即用**：双击 `index.html` 即可运行，无需安装任何环境。

## 🧠 原创框架：生命光谱模型（LSM-120）

本测试的核心是一个**原创理论框架**，把一个人的内在心理资源看作一道由 12 条光带组成的**光谱**：

| 光谱域 | 维度 | 简要定义 |
|---|---|---|
| 认知光谱 | 认知弹性 | 面对变化调整观点与策略的灵活程度 |
| 认知光谱 | 专注锚定 | 干扰下的注意力保持与回锚能力 |
| 认知光谱 | 好奇探索 | 对未知与不确定的主动接近 |
| 认知光谱 | 决策权衡 | 审慎分析型 vs 直觉行动型 |
| 情绪光谱 | 情绪复原 | 负性事件后情绪回落的速率 |
| 情绪光谱 | 压力代谢 | 对持续压力的"消化"效率 |
| 情绪光谱 | 乐观基调 | 基于自我效能的建设性预期 |
| 情绪光谱 | 情绪觉知 | 对自身情绪的识别与命名 |
| 关系光谱 | 边界建构 | 建立清晰灵活的人际界限 |
| 关系光谱 | 社交能量 | 互动带来充盈还是耗竭 |
| 关系光谱 | 共情通道 | 理解与感受他人的能力 |
| 内在锚定域 | 独立自主 | 不依赖外部确认的内在一致 |

**计分方式**：每题 1–5 分，反向题自动反转，每维度标准化为 0–100 分，并按"低亮 / 中亮 / 高亮"三段解读。聚合得到心理平衡指数（PBI）与光谱一致性（SC）。

> 完整理论、计分与解读规范见 [docs/framework.md](docs/framework.md)。

## 🧭 答题机制说明（原创设计）

- **维度交错**：题目按维度轮流出题（而非连续同类题），减少连续作答同一维度时的惯性偏差。
- **反向题**：41 道反向题穿插其中，降低"全选同一档"的作答模式误差。
- **进度可视**：顶部进度条实时显示作答进度。
- **本地即时**：全部计算在本机完成，即时生成结果与图谱。
